E1-2	Write a Python program to encrypt and decrypt a message using a One-Time Pad.

Theory — OTP কী?
OTP = One-Time Pad

পৃথিবীর সবচেয়ে নিরাপদ encryption!
তাত্ত্বিকভাবে সম্পূর্ণ অটুট!
Caesar vs OTP
Caesar:
H → K  (সবসময় একই shift = 3)
H → K  (আবারও একই!)

OTP:
H → K  (shift = 3)
H → N  (shift = 6)  ← প্রতিবার আলাদা!
কীভাবে কাজ করে?
message এর প্রতিটি অক্ষরের জন্য
আলাদা আলাদা random key ব্যবহার করো

message = "HELLO"
key     = "XQMBT"  ← সম্পূর্ণ random!

H + X → ?
E + Q → ?
L + M → ?
L + B → ?
O + T → ?
Encrypt সূত্র
(t + k) % 26

t = message অক্ষরের নম্বর (0-25)
k = key অক্ষরের নম্বর (0-25)

H=7, X=23
(7 + 23) % 26 = 30 % 26 = 4 → E

HELLO → EVXMH
Decrypt সূত্র
(c - k) % 26

c = cipher অক্ষরের নম্বর
k = key অক্ষরের নম্বর

E=4, X=23
(4 - 23) % 26 = -19 % 26 = 7 → H ✅

Python এ % সবসময় ধনাত্মক দেয়!
কেন সম্পূর্ণ অটুট?

def encrypt(text, shift):
    return ''.join(
        chr((ord(c) - (65 if c.isupper() else 97) + shift) % 26 + (65 if c.isupper() else 97))
        if c.isalpha() else c for c in text)

def prepare(t):
    t = t.upper().replace("J","I").replace(" ","")
    p, i = [], 0
    while i < len(t):
        a = t[i]; b = t[i+1] if i+1<len(t) else 'X'
        if a == b: p.append(a+'X'); i += 1
        else: p.append(a+b); i += 2
    return p

def encrypt(text, key):
    m = make_matrix(key)
    res = ""
    for a,b in prepare(text):
        r1,c1 = find(m,a); r2,c2 = find(m,b)
        if r1==r2: res += m[r1][(c1+1)%5] + m[r2][(c2+1)%5]
        elif c1==c2: res += m[(r1+1)%5][c1] + m[(r2+1)%5][c2]
        else: res += m[r1][c2] + m[r2][c1]
    return res

def decrypt(text, key):
    m = make_matrix(key)
    res = ""
    for i in range(0,len(text),2):
        a,b = text[i], text[i+1]
        r1,c1 = find(m,a); r2,c2 = find(m,b)
        if r1==r2: res += m[r1][(c1-1)%5] + m[r2][(c2-1)%5]
        elif c1==c2: res += m[(r1-1)%5][c1] + m[(r2-1)%5][c2]
        else: res += m[r1][c2] + m[r2][c1]
    return res

def mod_inverse(a, m):
    a = a % m
    for x in range(1, m):
        if (a * x) % m == 1:
            return x
    return None

একটাই key দিয়ে encrypt ও decrypt করে
তাই বলে Symmetric Encryption
মূল ধারণা
RSA → দুটো key (Public + Private)
DES → একটাই key (Secret)

একই key দিয়ে:
Encrypt → তালা লাগাও
Decrypt → খোলো
Block কী?
DES একসাথে ৮টি অক্ষর নিয়ে কাজ করে

message = "HELLO WORLD"
Block 1 = "HELLO WO"  ← ৮টি
Block 2 = "RLD"       ← মাত্র ৩টি!
Padding কী?
Block এ ৮টি না হলে ভরাট করো

"RLD" → "RLD\x05\x05\x05\x05\x05"
         ↑
         ৫টি ভরাট হলো

Decrypt এর পরে ভরাট সরাও → Unpadding
ECB Mode কী?
ECB = Electronic Codebook

প্রতিটি Block আলাদা আলাদা encrypt হয়

Block 1 → Encrypt → Cipher 1
Block 2 → Encrypt → Cipher 2
Block 3 → Encrypt → Cipher 3
Key কেন ৮ byte?
DES এ key = 64 bit = 8 byte

৮ অক্ষরের বেশি দিলে → কেটে ফেলো
৮ অক্ষরের কম দিলে  → স্পেস দিয়ে ভরাট

def encrypt(msg, key):
    key = key.encode()[:8].ljust(8, b' ')
    cipher = DES.new(key, DES.MODE_ECB)
    ct = cipher.encrypt(pad(msg.encode(), 8))
    return ct

def decrypt(ct, key):
    key = key.encode()[:8].ljust(8, b' ')
    cipher = DES.new(key, DES.MODE_ECB)
    pt = unpad(cipher.decrypt(ct), 8)
    return pt.decode()

E2-2	Write a Python program to encrypt and decrypt a message using the RSA algorithm.

Theory — RSA কী?
RSA = Rivest, Shamir, Adleman
তিনজন বিজ্ঞানীর নামে নামকরণ

পুরো internet এর security এর ভিত্তি!
Bank, Gmail, Facebook সব RSA ব্যবহার করে
মূল ধারণা
দুটো চাবি থাকে:

Public Key  → সবাইকে দাও (তালা)
Private Key → শুধু নিজে রাখো (চাবি)

Public key দিয়ে encrypt করো
Private key দিয়ে decrypt করো
RSA এর ৫টি ধাপ
ধাপ ১ — দুটো Prime Number নাও
p = 61
q = 53
ধাপ ২ — n বের করো
n = p × q
n = 61 × 53
n = 3233

এটা Public Key এর অংশ
ধাপ ৩ — phi বের করো
phi = (p-1) × (q-1)
phi = 60 × 52
phi = 3120

এটা গোপন রাখতে হবে!
ধাপ ৪ — e নাও (Public Exponent)
e = 17

শর্ত:
১। e এবং phi এর GCD = 1 হতে হবে
   GCD(17, 3120) = 1 ✅

Public Key = (e, n) = (17, 3233)
ধাপ ৫ — d বের করো (Private Exponent)
e × d ≡ 1 (mod phi)
17 × d ≡ 1 (mod 3120)

d = 2753

যাচাই:
17 × 2753 = 46801
46801 % 3120 = 1 ✅

Private Key = (d, n) = (2753, 3233)
Encrypt কীভাবে হয়?
message = 65
e = 17
n = 3233

c = m^e mod n
c = 65^17 mod 3233
c = 2790

Encrypted = 2790
Decrypt কীভাবে হয়?

d = 2753
n = 3233

m = c^d mod n
m = 2790^2753 mod 3233

Decrypted = 65
Code — ধাপে ধাপে
rsa_keygen() ফাংশন
python
def rsa_keygen(p, q, e):
    n = p * q
    phi = (p-1) * (q-1)
    d = pow(e, -1, phi)
    return (e, n), (d, n)
n = 61 × 53 = 3233
phi = 60 × 52 = 3120

pow(e, -1, phi)
→ e এর modular inverse বের করে
→ এমন d যেন e×d % phi = 1
→ d = 2753

return:
Public Key  = (17, 3233)
Private Key = (2753, 3233)
rsa_encrypt() ফাংশন
python
def rsa_encrypt(m, pub):
    e, n = pub
    return pow(m, e, n)
pub = (17, 3233)
e = 17, n = 3233

pow(65, 17, 3233)
= 65^17 mod 3233
= 2790
rsa_decrypt() ফাংশন
python
def rsa_decrypt(c, priv):
    d, n = priv
    return pow(c, d, n)
priv = (2753, 3233)
d = 2753, n = 3233

pow(2790, 2753, 3233)
= 2790^2753 mod 3233
= 65 ✅

এক কথায়
p, q     → দুটো prime number

E2-3	Write a Python program to simulate the Diffie-Hellman key exchange

Theory — Diffie-Hellman কী?
দুইজন মানুষ গোপনে key আদান-প্রদান করতে চায়
হ্যাকার সব দেখছে কিন্তু বুঝতে পারছে না!
এটাই Diffie-Hellman!
তালার উদাহরণ
সবাই জানে:
p = 7  (prime number)
g = 3  (primitive root)

শুধু Alice জানে:
a = 4  (Alice এর private key)

শুধু Bob জানে:
b = 5  (Bob এর private key)
৩টি ধাপ
ধাপ ১ — Public Key বানাও
Alice বানায়:
A = g^a mod p
A = 3^4 mod 7
A = 81 mod 7
A = 4  ← সবাইকে দিল

Bob বানায়:
B = g^b mod p
B = 3^5 mod 7
B = 243 mod 7
B = 5  ← সবাইকে দিল
ধাপ ২ — Shared Key বানাও
Alice হিসাব করে:
key1 = B^a mod p
key1 = 5^4 mod 7
key1 = 625 mod 7
key1 = 2 ✅

Bob হিসাব করে:
key2 = A^b mod p
key2 = 4^5 mod 7
key2 = 1024 mod 7
key2 = 2 ✅
ধাপ ৩ — কেন দুটো key সমান?
key1 = B^a mod p
     = (g^b)^a mod p
     = g^(a×b) mod p

key2 = A^b mod p
     = (g^a)^b mod p
     = g^(a×b) mod p

দুটোই g^(a×b) mod p
তাই সবসময় সমান! ✅
হ্যাকার কী দেখে?
হ্যাকার দেখে:     হ্যাকার দেখে না:
p = 7   ✅         a = 4  ❌
g = 3   ✅         b = 5  ❌
A = 4   ✅
B = 5   ✅

shared key = 2 বের করতে পারে না! ✅
Code — ধাপে ধাপে
Input
python
p = int(input("Enter prime number (p): "))    # p = 7
g = int(input("Enter primitive root (g): "))  # g = 3
a = int(input("Enter Alice private key: "))   # a = 4
b = int(input("Enter Bob private key: "))     # b = 5
Public Key
python
A = pow(g, a, p)   # Alice এর public key
B = pow(g, b, p)   # Bob এর public key
A = pow(3, 4, 7) = 3^4 mod 7 = 81 mod 7 = 4
B = pow(3, 5, 7) = 3^5 mod 7 = 243 mod 7 = 5
Shared Key
python
key1 = pow(B, a, p)   # Alice হিসাব করে
key2 = pow(A, b, p)   # Bob হিসাব করে
key1 = pow(5, 4, 7) = 5^4 mod 7 = 625 mod 7  = 2
key2 = pow(4, 5, 7) = 4^5 mod 7 = 1024 mod 7 = 2

এক কথায়
g, p      → সবাই জানে
a, b      → শুধু নিজে জানে
A, B      → public key, সবাইকে দেয়
key1=key2 → গোপন shared key

E2-5 Write a Python program to compute the GCD of two numbers using the Extended Euclidean Algorithm.

Theory
সাধারণ GCD vs Extended GCD
সাধারণ GCD:
GCD(48, 18) = 6
শুধু এটুকুই বলে

Extended GCD:
GCD(48, 18) = 6
এর সাথে x, y বের করে

যেন: 48×x + 18×y = 6 হয়
কেন x, y দরকার?
RSA Cryptography তে
Private key বের করতে
এই x, y লাগে!
Code — ধাপে ধাপে
Base Case
python
if b == 0:
    return a, 1, 0
b = 0 হলে GCD = a
কেন x=1, y=0 দিলাম?

a×1 + 0×0 = a ✅
সমীকরণ মেলে তাই!
Recursive Call
python
gcd, x1, y1 = extended_gcd(b, a % b)
নিজেই নিজেকে ডাকে
ছোট সংখ্যা দিয়ে আবার চালায়

extended_gcd(48, 18)
   → extended_gcd(18, 12)
      → extended_gcd(12, 6)
         → extended_gcd(6, 0)
            → থামো! b=0

x = y1
y = x1 - (a // b) * y1
আগের ধাপের x1, y1 নিয়ে
নতুন x, y বানাও

x = y1 = 1
y = x1 - (18//12) × y1
y = 0  - 1 × 1 = -1
